# Webinario 8.1 · Urban Routes — Ejecutar, depurar y sincronizar código

Repositorio de práctica del webinario 8.1 (Sprint 8).

## Antes del webinario

1. Ten listos PyCharm, Git y tu cuenta de GitHub conectada a PyCharm (lecciones 8.1.x y 8.2.x).
2. Ten a mano tu repositorio de las lecciones (`Nuevo_Repositorio`) clonado en tu computadora.
3. Clona **este** repositorio: en PyCharm, **File → Project from Version Control**, pega la URL y haz clic en **Clone**.

> Este repositorio es **de solo lectura** para ti: aquí ejecutas, depuras y traes actualizaciones (Fetch/Pull).
> Tus commits, push, ramas y pull requests los harás en **tu propio** `Nuevo_Repositorio`.

## Archivos

| Archivo | Para qué lo usamos |
|---|---|
| `tarifa_con_promo.py` | Ejecutar el proyecto y depurar una discrepancia (tarea guiada) |
| `descuento_largo.py` | Depurar un caso similar (práctica en la sala principal) |
| `.gitignore` | Archivos que Git debe ignorar |

Durante el webinario, el tutor agregará un archivo nuevo a este repositorio. Lo traerás a tu computadora con **Fetch** y **Pull**.
